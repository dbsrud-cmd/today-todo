# 오늘 뭐부터 하지?

HTML + CSS + JavaScript로 만든 개인용 할 일 앱입니다. API 키와 결제가 필요 없습니다.

## 사용

index.html을 더블클릭하거나 로컬 서버를 실행합니다.

    Set-Location D:\today-todo
    node server.cjs

주소: http://127.0.0.1:3000 / 종료: Ctrl+C

중요도는 높음 ★★★, 보통 ★★, 낮음 ★입니다. 추가·수정 화면에서 선택합니다.
추천 순서는 중요도 → 같은 중요도에서 마감일 → 같은 조건에서 추가 순서입니다.
완료한 항목은 추천에서 제외하며 원본 목록의 순서는 유지합니다.
추천은 브라우저 안에서 계산하며 외부 요청이나 비용이 없습니다.

## 저장과 백업

같은 브라우저·프로필·주소에서 목록과 완료 상태를 복원합니다.
파일 주소와 서버 주소의 저장 공간은 다릅니다. 백업 내려받기와 복원으로 옮길 수 있습니다.
복원하면 현재 목록을 교체하므로 먼저 백업하세요.

기존 .env는 보존했지만 현재 앱은 읽거나 사용하지 않습니다. 키가 더 필요하지 않으면 OpenAI 계정에서 폐기할 수 있습니다.

## 테스트

    node --test tests/*.test.cjs

브라우저 테스트에는 Playwright와 Edge가 필요합니다.
